# ระบบแจ้งซ่อม (PHP + SQLite)

ระบบแจ้งซ่อม/แจ้งงานแบบเบา ๆ ไม่ต้องติดตั้งฐานข้อมูลแยก ใช้ได้บนโฮสติ้ง PHP ทั่วไป

## ความต้องการ
- PHP 8.0 ขึ้นไป (เปิด extension `pdo_sqlite` และ `fileinfo`)

## วิธีติดตั้ง
1. อัปโหลดทั้งโฟลเดอร์ขึ้นเซิร์ฟเวอร์
2. ให้สิทธิ์เขียนโฟลเดอร์ `data/` และ `uploads/` (เช่น `chmod 775`)
3. เปิด `config.php` แล้ว **เปลี่ยน `ADMIN_PASSWORD`**
4. เข้า `index.php` ได้เลย ระบบจะสร้างตารางให้อัตโนมัติ

ทดสอบบนเครื่องตัวเอง: `php -S localhost:8000` แล้วเปิด http://localhost:8000

## หน้าต่าง ๆ
| ไฟล์ | หน้าที่ |
|---|---|
| `index.php` | รายการทั้งหมด + สถิติ + ค้นหา/กรอง |
| `repair_new.php` | ฟอร์มแจ้งซ่อม (แนบรูปได้ 5 รูป) |
| `repair_view.php` | รายละเอียด, ขั้นตอน, ประวัติ, ผู้ดูแลอัปเดตสถานะ/ลบ |
| `track.php` | ติดตามสถานะด้วยรหัสงาน |
| `login.php` | เข้าสู่ระบบผู้ดูแล |

## นำไปใช้งานอื่น
แก้เฉพาะ `config.php`:
- `APP_NAME`, `ITEM_LABEL`, `CODE_PREFIX` — ชื่อระบบและรหัสงาน
- `CATEGORIES` — ประเภทงาน (เช่น ห้องประชุม/รถตู้ สำหรับระบบจอง)
- `PRIORITIES`, `STATUSES` — ระดับความเร่งด่วนและขั้นตอนงาน (สีที่ใช้ได้: gray, blue, orange, red, green, purple)

ตัวอย่าง: ระบบแจ้งปัญหา IT → `CODE_PREFIX = 'IT'`, เปลี่ยนหมวดเป็น อินเทอร์เน็ต/ปริ้นเตอร์/บัญชีผู้ใช้

## ความปลอดภัย
- มี CSRF token ทุกฟอร์ม, escape ข้อมูลทุกจุด, ใช้ prepared statement
- ตรวจชนิดไฟล์อัปโหลดจากเนื้อไฟล์จริง (รับเฉพาะรูป)
- `.htaccess` กันการเข้าถึงไฟล์ฐานข้อมูลและกันรันสคริปต์ในโฟลเดอร์ uploads (Apache)
  ถ้าใช้ Nginx ให้ตั้ง `location ~ ^/(data|uploads/.*\.php) { deny all; }`
