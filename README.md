# ระบบแจ้งซ่อม (Repair Request System)

ระบบแจ้งซ่อม/แจ้งงานภาษาไทย เขียนด้วย **PHP 8 ล้วน + SQLite**
ไม่ต้องติดตั้ง MySQL, ไม่ต้องใช้ Composer, ไม่ต้องรันคำสั่งติดตั้งใด ๆ

## ✨ ความสามารถ
- ฟอร์มแจ้งซ่อม แนบรูปได้สูงสุด 5 รูป และถ่ายจากมือถือได้ทันที
- ออกรหัสงานอัตโนมัติ เช่น `RP-2569-0001` ให้ผู้แจ้งใช้ติดตามสถานะเองได้
- หน้ารายการพร้อมสถิติ ค้นหา และกรองตามสถานะ/ประเภท
- แถบขั้นตอนงานและประวัติการดำเนินงาน (timeline)
- ผู้ดูแลอัปเดตสถานะ มอบหมายช่าง เขียนบันทึก และลบงานได้
- ใช้งานบนมือถือได้ (responsive)

## 🚀 ใช้งาน (ไม่ต้องติดตั้ง)

### บนโฮสติ้ง (cPanel / Plesk / DirectAdmin)
1. ดาวน์โหลดโค้ด: ปุ่ม **Code → Download ZIP**
2. อัปโหลดและแตกไฟล์ไว้ใน `public_html/` หรือโฟลเดอร์ย่อย
3. เปิดเว็บ → ระบบสร้างฐานข้อมูลและโฟลเดอร์ให้อัตโนมัติ
4. คลิก **ผู้ดูแล** เพื่อตั้งรหัสผ่านผู้ดูแลครั้งแรก เท่านี้ก็พร้อมใช้งาน

> ถ้าขึ้นข้อความ "เขียนไฟล์ไม่ได้" ให้ตั้งสิทธิ์โฟลเดอร์หลักเป็น 755/775
> ถ้าขึ้น "ไม่พบ pdo_sqlite" ให้เปิดใน cPanel → *Select PHP Version* → ติ๊ก `pdo_sqlite`

### ทดสอบบนเครื่องตัวเอง
ต้องมี PHP 8 ในเครื่อง (หรือใช้ XAMPP / Laragon) แล้วรันในโฟลเดอร์นี้:
```bash
php -S localhost:8000
```
จากนั้นเปิด http://localhost:8000

## 📁 โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `config.php` | ตั้งค่าระบบ ฐานข้อมูล และ layout |
| `index.php` | รายการทั้งหมด + สถิติ + ค้นหา/กรอง |
| `repair_new.php` | ฟอร์มแจ้งซ่อม |
| `repair_view.php` | รายละเอียดงาน และส่วนอัปเดตของผู้ดูแล |
| `track.php` | ติดตามสถานะด้วยรหัสงาน |
| `login.php` | ตั้ง/เข้าสู่ระบบรหัสผ่านผู้ดูแล |
| `data/` | ฐานข้อมูล SQLite (สร้างอัตโนมัติ, ไม่ขึ้น git) |
| `uploads/` | รูปที่แนบ (สร้างอัตโนมัติ, ไม่ขึ้น git) |

## 🔧 นำไปใช้งานอื่น
แก้เฉพาะส่วนบนของ `config.php`:
- `APP_NAME`, `ORG_NAME`, `ITEM_LABEL`, `CODE_PREFIX` — ชื่อระบบ หน่วยงาน และรหัสงาน
- `CATEGORIES` — ประเภทงาน
- `PRIORITIES`, `STATUSES` — ความเร่งด่วนและขั้นตอนงาน (สี: gray, blue, orange, red, green, purple)

ตัวอย่างเช่น
- **ระบบแจ้งปัญหา IT:** `CODE_PREFIX = 'IT'` หมวด = อินเทอร์เน็ต / ปริ้นเตอร์ / บัญชีผู้ใช้
- **ระบบขอใช้ห้อง/รถ:** หมวด = ห้องประชุม / หอประชุม / รถตู้ สถานะ = รออนุมัติ / อนุมัติ / ไม่อนุมัติ

## 🔒 ความปลอดภัย
- รหัสผ่านผู้ดูแลตั้งผ่านหน้าเว็บและเก็บแบบ hash ไม่มีรหัสเริ่มต้นฝังอยู่ในโค้ด
- มี CSRF token ทุกฟอร์ม, escape ข้อมูลทุกจุด และใช้ prepared statement
- ตรวจชนิดไฟล์อัปโหลดจากเนื้อไฟล์จริง (รับเฉพาะรูปภาพ)
- สร้าง `.htaccess` อัตโนมัติ เพื่อกันการดาวน์โหลดฐานข้อมูลและกันการรันสคริปต์ใน `uploads/` (Apache)
- ถ้าใช้ **Nginx** ให้เพิ่ม:
  ```nginx
  location ^~ /data/ { deny all; }
  location ~ ^/uploads/.*\.(php|phtml|phar)$ { deny all; }
  ```

## 💾 สำรองข้อมูล
คัดลอกไฟล์ `data/app.sqlite` และโฟลเดอร์ `uploads/` เก็บไว้ก็เพียงพอ
